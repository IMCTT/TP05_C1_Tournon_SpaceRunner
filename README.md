# Space Runner

Sidescroller runner donde tu personaje corre automáticamente y debe esquivar enemigos mientras recolecta power-ups para sobrevivir el mayor tiempo posible.

---

## 🎮 Controles

| Acción | Tecla |
|---|---|
| Saltar | Espacio |

El personaje corre automáticamente hacia adelante — el único input del jugador es el salto, usado para esquivar obstáculos y enemigos.

---

## ❤️ Sistema de vidas

- El jugador comienza con **5 vidas**.
- Al entrar en contacto con un **enemigo**, pierde **1 vida**.
- Al agarrar un **power-up**, recupera **1 vida**.
- Al agarrar un **power-up**, recupera **gana invincibilidad**.
- Al llegar a 0 vidas, termina la partida (Game Over).

---

## 🚀 Cómo correrlo localmente

1. Cloná el repositorio:
   ```bash
   git clone https://github.com/<usuario>/SpaceRunner.git
   ```
2. Abrí el proyecto con **Unity**
3. Abrí la escena principal: `Assets/Scenes/MainMenu.unity`.
4. Play.
